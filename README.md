# Glance – telefoonpagina

Kleine pagina voor de Glance-app (tv/pc):
- **Telefoon als toetsenbord**: scan de QR-code bij het schermtoetsenbord op de tv.
- **Tv inloggen**: scan de QR-code bij Instellingen → Account → "Inloggen met code".

Bevat alleen de publieke Supabase-URL en publishable key; gegevens zijn beschermd met Row Level Security.
Gegenereerd vanuit de Glance-repo (`npm run build:link`).
